Coins with full 3D rotation

Each coin is a real disc in 3D: any orientation (pitch, yaw and roll together) is a rotation matrix, drawn with the game's own pixel coin art. Its face turns edge-on, you see the reeded edge's thickness, then the back. Drag the big coin to spin it any way; let go to fling it.

Copper, silver, gold, platinum, titanium and a ruby coin, each on its own axis. The coin bag in the game uses the same coins and physics.
